# משמר הפירמידה השחורה

משחק תלת־ממד בדפדפן (Three.js r160). **כל הגרפיקה נבנית בקוד בלבד**: צורות הנדסיות, חומרים ו-shaders. אין בפרויקט אף קובץ תמונה או טקסטורה.
ספריית Three.js כלולה בתיקייה `vendor/`, כך שהמשחק עובד גם בלי אינטרנט.

## הרצה
```bash
cd desert-pyramid
python3 -m http.server 8000
```
ואז לפתוח בדפדפן: http://localhost:8000
(או פשוט `./start.sh` במק/לינוקס, `start.bat` בווינדוס)

> צריך שרת מקומי ולא לחיצה כפולה על index.html, כי דפדפנים חוסמים מודולי JS מ-`file://`.

## אתר
גרסת האתר נבנית עם `python3 tools/build_site.py` (יוצר `site.html`). בטלפון מופיעים ג'ויסטיק וכפתורי מגע.

## הטיימר
2 שעות אמיתיות = 24 שעות בעולם (5 דקות אמיתיות = שעת משחק). היום מתחיל ב-06:00 עם מחזור יום ולילה מלא.
הטיימר רץ בזמן אמת **כל עוד המשחק פתוח** (גם בלשונית ברקע) ואין כפתור עצירה. הוא עוצר רק כשסוגרים את הדף, ונשמר ב-localStorage.
ב-4 השעות האחרונות סופת חול סוגרת על המדבר.

**כל סוף דורש לפחות 40 דקות משחק:** שער הפירמידה נפתח רק בשעה 14:00 בעולם, כלומר אחרי 40 דקות אמיתיות, וסוף "הזמן נגמר" מגיע רק אחרי שעתיים.

## העלילה
לפני 3000 שנה כלא מלך הליקוי **סת'אר** את השמש האפלה בפירמידה שחורה. אחותו, הכוהנת **נפירה**, יצרה מחול העיר כם-אשר את **חארו, משמר החול**. עכשיו החותם נסדק.

| פרק | מה עושים |
|---|---|
| 1. ההתעוררות | פוגשים את רוחה של נפירה בשדרת הספינקסים |
| 2. מילות השמש | מוצאים את **תאמון הזקן** במערב ומביאים לו 5 לוחות זהב |
| 3. רסיס השחר | חידת סדר אבנים (5 צעדים) במקדש המזרחי |
| 4. השיירה האבודה | **לינה** מבקשת עזרה; מחלצים את השיירה של **יאסיף** (אופציונלי, משנה סופים) |
| 5. שומר העצמות | 3 חידות של רוח החיה הענקית בדרום; טעות = המתנה של 2 דקות |
| 6. רסיס הצהריים | מופיע רק אחרי 11:00; חידת סדר ארוכה (7 צעדים) |
| 7. האחיות | מעירים 3 מראות על הפירמידות הקטנות, והן חושפות את רסיס הלילה |
| 8. השער | נפתח ב-14:00. השיחה האחרונה עם נפירה וסת'אר, ואז הבחירה |

בנוסף: 7 **חיפושיות זיכרון** שחושפות את העבר של חארו (ומשנות את סוף הסיפור), לחישות של סת'אר אחרי כל רסיס, ו**יומן** (J) שמתעד הכול.

```
├── tools/build_site.py   בונה את site.html לגרסת האתר
└── vendor/three/     Three.js (רישיון MIT)
```
